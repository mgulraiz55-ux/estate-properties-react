## Project Overview

ESTATE is a modern luxury real estate platform designed for premium properties, private advisory services, global investors, and high-net-worth clients.

The website combines elegant visual design with responsive layouts, cinematic imagery, smooth interactions, and production-focused performance optimization.

## Run Locally

Clone the repository:

```bash
git clone https://github.com/mgulraiz55-ux/estate-properties-react.git
```

Open the project folder:

```bash
cd estate-properties-react
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

---

## Production Build

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

---

## Firebase Deployment

```bash
npm run build
firebase deploy --only hosting
```
